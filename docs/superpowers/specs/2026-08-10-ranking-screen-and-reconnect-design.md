# 순위 화면 단장 + 서버 재연결

2026-08-10. 사용자 요청 두 건을 한 묶음으로 다룬다.

1. "랭킹 탭이 너무 단조롭다. 단상이 더 멋있었으면 좋겠다."
2. "랭킹을 열 때 서버가 연결 안 돼서 못 여는 경우가 많다. 실행할 때 연결해 놓고
   시작하면 안 되나?"

## 전제 — 이미 부팅 때 붙고 있다

`main.ts` 는 첫 화면을 띄우자마자 `bootAccount()` 로 `store.connect(net)` 을 부른다.
그러니 "실행할 때 연결한다"는 이미 되어 있다. 실제 증상의 원인은 **재시도가 없다**는
것이다.

- `AccountStore.connect` 는 실패하면 `this.net = null` 로 두고 끝난다. 그 세션 내내
  오프라인이라 순위·상점·매칭이 모두 죽는다. 새로고침 전에는 회복할 길이 없다.
- `fetchBoard` 도 호출 한 번이 실패하면 그대로 `null` 을 준다.
- 연결 타임아웃은 8초(`CALL_TIMEOUT_MS`). 느린 회선에서는 부팅 창에 자주 걸린다.

그래서 고칠 곳은 "부팅 연결"이 아니라 **재연결**이다.

## A. 순위 화면

에셋 제약: `game/public/assets/` 는 `.gitignore` 에 있다(라이선스). **새 PNG 를 만들지
않는다.** 왕관·메달은 인라인 SVG 와 CSS 로 그린다.

### 배경

지금은 순수 검정이라 무대가 아니라 목록으로 읽힌다. 시상대 뒤에 방사형
스포트라이트(`radial-gradient`) 하나와 발밑 무대 바닥 선 하나를 깐다. 요소는
`#board` 안의 고정 레이어 한 장이고 스크롤을 안 탄다.

### 제목

`.shop-title` 을 공용으로 쓰고 있어 흐린 회색이다. 순위 전용 클래스로 떼고 금색
구분선을 붙인다.

### 시상대

- 단상을 입체로. `::before` 로 윗면(밝은 평행사변형), 정면은 그라디언트, 안쪽
  그림자로 두께를 낸다.
- 1등 왕관은 인라인 SVG, 2·3등은 원형 메달 배지(금·은·동).
- **아바타를 붙인다.** 지금 시상대에는 없고 목록에만 있어 두 영역이 따로 논다.
- 등수 숫자를 키우고 음각 느낌의 `text-shadow` 를 준다.
- 내 자리 표시가 지금은 이름 색뿐이다. 단상 테두리까지 하늘색으로 넓힌다.

### 목록

- 등수가 `ol` 기본 번호라 흐린 작은 글씨다. `list-style` 을 끄고 **코드가 등수 배지를
  직접 그린다** (`start` 속성도 같이 걷어낸다).
- 4·5등만 금속 톤 테두리를 옅게 준다 — 상위권이 목록 안에서도 구분된다.
- 행 높이에 여유를 주고 홀짝 대비를 미세하게 넣는다.

### 하단 내 순위 줄

`.board-list` 바깥, 뒤로가기 버튼 위에 고정한다. `내 순위 127위 / 340명` 과
아바타·이름·점수를 적는다. 화면 아래 절반이 비던 자리를 이것이 채운다.

### 움직임

**애니메이션은 넣지 않는다** (2026-08-10 사용자 선택). 정적으로만 멋을 낸다.

## B. 서버 — 내 등수

`getLeaderboard` 는 상위 `BOARD_SIZE`(10) 줄만 준다. 내가 10위 밖이면 내 등수를 알
방법이 지금은 없다. 반환을 배열에서 객체로 바꾼다.

```js
{ rows: [...], myRank: number | null, total: number }
```

- `myRank` = `countCollectionItems(rating > 내 점수) + 1`.
- `total` = `countCollectionItems()`.
- 표에 내 칸이 없으면(이름 미설정 등) `myRank` 는 `null`.
- `>` 연산자는 harness 가 이미 지원한다 (`tools/server-harness.mjs`).

**하위호환**: 클라이언트는 배열이 오면 옛 서버로 보고 `myRank = null`, `total =
rows.length` 로 다룬다. 서버와 클라이언트의 배포 시점이 어긋나도 화면이 안 깨진다.

## C. 재연결

- `AccountStore.ensureOnline(): Promise<boolean>` 을 새로 둔다. 붙어 있으면 즉시
  `true`, 아니면 재연결을 시도한다.
- **진행 중인 시도를 재사용한다.** 여러 화면이 동시에 부르면 소켓이 경쟁한다 —
  `agent8.ts` 의 `connect` 주석이 짚어 둔 그 문제다(재연결이 살아 있는 소켓을 먼저
  닫는다).
- `bootAccount` 는 실패하면 백오프로 세 번 더 시도한다 (2초 · 5초 · 10초). 성공하면
  `afterConnect()` 로 화면을 다시 판단한다.
- 순위·상점·매칭에 들어갈 때 `ensureOnline()` 을 먼저 부른다.
- 순위 화면은 `연결 중…` 을 띄우고, 실패하면 지금의 오프라인 문구와 함께 **다시 시도**
  버튼을 남긴다.
