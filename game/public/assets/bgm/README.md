# 배경음 (BGM)

| 파일 | 언제 나는가 |
|---|---|
| `lobby.mp3` | 로비·상점·순위·설정 |
| `match.mp3` | 판이 도는 동안 |

**둘 다 없어도 된다.** 없으면 조용히 넘어간다 (`sfx/README.md` 와 같은 규칙).

## 만들 때 지킬 것

- **이음매 없이 반복되어야 한다.** 끝과 시작이 안 맞으면 한 바퀴마다 툭 끊긴다.
  판이 90초인데 반복이 30초면 세 번 돈다 — 티가 크게 난다
- **효과음보다 확실히 작게.** 배경음이 `capture` 를 덮으면 정보가 사라진다.
  코드에서 배경음 음량을 따로 두지만(`bgmVolume`) 원음도 낮게 깔아 둘 것
- 길수록 좋다. 60~120초면 반복이 덜 지겹다
- 파일이 크면 첫 로딩이 늘어진다. 128kbps 모노로 60초면 약 1MB

## 배속과의 관계

배속(1.5×·2×)에서 **배경음은 안 빨라진다.** 판만 빨라지고 음악은 그대로다 —
`playbackRate` 를 올리면 음정이 같이 올라가 딴 곡이 된다.
