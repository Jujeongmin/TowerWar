# 효과음 (SFX)

여기에 아래 이름 그대로 넣으면 코드는 안 고쳐도 된다. **`.mp3` 로 통일한다** —
`.ogg` 는 iOS 사파리에서 안 되는 경우가 있고, 한 형식만 쓰면 로더가 단순해진다.

**없는 파일은 조용히 무시된다.** 그림이 없을 때 원·도형으로 떨어지는 것과 같은 규칙이다
(`README.md` 의 "그림이 저장소에 없다"). 하나씩 채워 넣어도 되고, 안 넣어도 게임은 돈다.

| 파일 | 언제 나는가 | 길이 권장 |
|---|---|---|
| `capture.mp3` | 타워를 뺏거나 뺏길 때. **이 게임에서 가장 중요한 사건** | 0.3~0.6초 |
| `clash.mp3` | 적 유닛끼리 부딪힐 때. 판당 수백 번 난다 — **짧고 작게** | 0.05~0.15초 |
| `route-open.mp3` | 경로를 열 때 | 0.1~0.2초 |
| `route-cut.mp3` | 경로를 끊을 때. 여는 것과 **반대 방향**으로 들려야 한다 | 0.1~0.2초 |
| `route-blocked.mp3` | 못 긋는 곳에 그었을 때 (거부) | 0.1~0.2초 |
| `match-start.mp3` | 판이 시작될 때 | 0.5~1.2초 |
| `victory.mp3` | 이겼을 때 | 1~2초 |
| `defeat.mp3` | 졌을 때 | 1~2초 |
| `tap.mp3` | 버튼을 누를 때 | 0.05~0.1초 |
| `purchase.mp3` | 상점에서 사거나 갈아입을 때 | 0.3~0.6초 |

## 만들 때 지킬 것

- **`clash` 는 아주 작게.** 판당 수백 번 난다. 다른 소리와 같은 크기로 만들면 그것만
  들린다. 코드에서 최소 간격(`MIN_GAP_MS`)과 동시 재생 수를 제한하지만, 원음 자체가
  작아야 한다
- **모노로 충분하다.** 세로형 모바일이고 위치감이 필요 없다
- **앞뒤 무음을 잘라 둘 것.** 앞에 무음이 있으면 눌렀을 때 늦게 나는 것처럼 들린다
- 44.1kHz / 128kbps 면 충분하다. 파일이 커질수록 첫 로딩만 늘어진다

## 이 폴더는 저장소에 안 올라간다

`game/public/assets/` 전체가 `.gitignore` 에 있다 (Tiny Swords 재배포 금지 때문).
**음원도 같이 무시된다.** 클론하면 소리가 없는 상태로 돈다.

음원이 직접 만든 것이거나 재배포가 허용된 라이선스라면 `.gitignore` 에서 이 폴더만
예외로 빼면 된다:

```gitignore
game/public/assets/
!game/public/assets/sfx/
!game/public/assets/bgm/
```

**단, 그 전에 라이선스를 확인할 것.** 저장소가 공개라 올리는 순간 재배포다.
